# 影人库（Film People）

Rei 2026-11-14 定的：资料库里加一个内置库「影人」，收关注的演员、导演、编剧等，可以和影视库里的片子连起来。追加：「影人手动加，和影片的关联也手动」。

一句话：影人是和影视库平级的一个库，影人和片子之间的关联全靠手动连。

## 叫法

- 中文「影人」，库名「影人库」；英文 Film People。其余语言：Personas del cine、Pessoas do cinema、Люди кино、映画人、Filmschaffende、Gens du cinéma、Insan film（外语待母语者看）。
- 图标用 Lucide `drama`，圆形头像版式，同人物库。
- 影人详情里的一节叫「作品」，影视详情里的一节叫「主创」。

## 不做的

- 不按 TMDB 演职员表自动匹配，不自动收录、不自动导入影人。
- 不列 TMDB 上的「其它作品」。
- 影视库列表不按影人筛选：资料库页现在只有搜索，没有筛选可接（见下面「没做的」）。

## 库本身

- 单开一个库，不并进人物库。人物库是生活里的人（person 表），影人是资料库里的资料（library_item），两边不通。
- 排在影视库后面。已经调过资料库顺序的设备上，它排在最后。
- 字段：

| 字段 | key | 种类 | 说明 |
|---|---|---|---|
| 名字 | `name` | 文字（主字段） | 中文界面填中文名 |
| 头像 | `photo` | 图片 | 圆形，存 R2 |
| 英文名 | `name_en` | 文字 | |
| 生年 | `birth_year` | 数字 | |
| 身份 | `roles` | 多选 | 默认 演员、导演、编剧、制片、配乐 |
| TMDB | `tmdb` | 站点编号 `tmdb_person` | 数字，显示成 themoviedb.org/person/… 链接 |
| IMDb | `imdb` | 站点编号 `imdb_name` | nm 开头，显示成 imdb.com/name/… 链接 |
| 更多链接 | `links` | 链接组 | |

- 简介写在资料的备注里（Markdown），资料详情照常显示。
- 「身份」要加别的选项（摄影、剪辑……）：资料库页「…」→「编辑资料库」→ 影人 → 身份，和别的多选字段一样加。

## 怎么加影人

都是手动的，点了才加：

1. 资料库页切到「影人」，点右上角加号，弹出「添加到影人库」。可以全部手填。
2. 想省事：填好名字（或 TMDB 编号、IMDb 编号）后点「自动补全」，从 TMDB 人物里挑一个，逐项勾选要填的：头像、名字、英文名、生年、身份、TMDB / IMDb 编号、简介。头像拉进 R2，和影视海报一样。
3. 也可以在影人库的搜索框里打名字，下面会列 TMDB 上的人，点一个直接加进库并打开它。粘贴 IMDb 影人链接（imdb.com/name/nm…）或 TMDB 人物链接也行。

TMDB 的规则：

- 搜索结果只有 TMDB 的主名，常是英文；选中后取详情，从别名里挑中文名。中文界面名字填中文名，英文名填拉丁字母那个；英文界面反过来。
- 身份按 TMDB 的「主要部门」给一个：Acting 演员、Directing 导演、Writing 编剧、Production 制片、Sound 配乐。
- 中文简介是空的就用英文简介。
- 自动补全时，已经填了的字段默认不勾，勾上才覆盖。备注写过东西，简介那行也默认不勾。

## 关联影片

- 影人详情「作品 N」一节列已经连上的片子：海报小图、片名、年份 · 角色，右边是这部片的观看任务状态。
  - 状态：有没做完的任务，写「进行中」（有一件在进行中）或「待办」；都做完了写最近结束那件的「完成」或「关闭」；一件任务都没有写「没有任务」。
  - 按片子年份排，新的在前；没填年份的排最后（我定的，同豆瓣、IMDb 的作品表）。
- 「关联影片」：上面填角色（可以不填，比如「导演」「主演·饰某某」），下面在影视库里搜着选，选中就连上。已经连着的行尾打勾，再点一下是断开。
- 每行右边「…」：改角色…、断开。断开后提示里能撤销。
- 点一行进那部片的资料页。

## 影视详情「主创」

- 只列已经连上的影人：圆形头像、名字、角色。没有别的演职员。
- 「关联影人」：同上，在影人库里搜着选。
- 「…」里同样能改角色、断开。
- 顺序按连上的先后。

## 数据

- 新表 `library_link`，迁移 v25：`id`、`from_item`（影人）、`to_item`（影片）、`role`、`sort`、`created_at`、`updated_at`、`deleted`。
- 行 id 由这一对算出（`libraryLinkId`），两台设备各自连同一对得到同一行，按 LWW 合并；断开打墓碑，再连上是同一行翻回来，角色换成这次填的。
- 一对只有一行，所以同一个人在一部片里既是导演又是编剧，就写在一个角色里：「导演、编剧」。
- 角色去掉首尾空白，连续空白并成一个，最多 80 个字。
- 同步走原来的行级 LWW；Worker 是通用行存储，不用改表。老客户端不认这张表，拉到的行直接忽略，不报错。
- 资料合并过：两端都顺着 `merged_into` 找到留下的那条，同一对只算最新那行。删一条资料时，连着它的关联一起断开。
- 导出写 `_meta/library_links.json`，导入时两端资料要在这次导入里或库里。
- 代码：`packages/core/src/library-link.ts`，Store 的 `libraryLinks`、`linksFromItem`、`linksToItem`、`linkLibraryItems`、`setLibraryLinkRole`、`unlinkLibraryItems`、`restoreLibraryLink`；界面 `apps/client/src/components/library/FilmLinks.tsx`；TMDB 人物在 Worker `apps/server/src/lookup/tmdb.ts`（`searchTmdbPeople`、`tmdbPerson`，`/find/nm…`）。测试 `packages/core/test/library-link.test.ts`、Worker `test/lookup.test.ts`、`test/sync.test.ts`。

## 没做的

- 影视库按影人筛选：资料库页现在只有搜索框，没有筛选条或筛选菜单，要接得新做一套筛选界面。影人详情的「作品」已经能看这个人连了哪些片，所以先不做。

## 待 Rei 确认

下面几条是我定的：

1. 作品按年份新的在前，没年份的排最后。
2. 一对影人和影片只有一行，多个身份写在一个角色里（「导演、编剧」）。
3. 观看任务状态：有没做完的写「进行中 / 待办」，否则写最近结束那件的状态，没有任务写「没有任务」。
4. 影视详情的「主创」一节总是显示，没连人时写「还没有关联的影人。」。
5. 「关联影片 / 影人」只从库里已有的挑，不能在那里新建；选中一条就连上并关掉面板。
6. 影人也能「用它新建任务」，任务也能挂影人当资料（和别的库一样）。
