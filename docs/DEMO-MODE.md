# 演示模式

Rei 2026-11-18 定的：新装默认是演示模式。演示数据单独放一个库，关掉演示模式就回到生产库，演示数据永远不进生产库。

## 两个库

| | 生产库 | 演示库 |
|---|---|---|
| Tauri（桌面、手机） | app 数据目录下的 `mindough.db` | 同目录的 `mindough-demo.db` |
| 网页 | OPFS 里的 `/mindough.db` | OPFS 里的 `/mindough-demo.db` |
| 退回 localStorage 时 | 键前缀 `mindough:v1:` | 键前缀 `mindough:demo:v1:` |
| 附件上传队列（IndexedDB） | `mindough-files` | `mindough-files-demo` |
| 同步 | 登录了就同步 | 完全不同步 |

- 开没开演示模式，只记在这台设备的 localStorage：`mindough:demo-mode`，`1` 是开，`0` 是关。它不进偏好表，也不同步。
- Tauri 的 Rust 端（`src-tauri/src/db.rs`）每个窗口、每个文件各开一条连接，写锁由 SQLite 排队（busy_timeout 15 秒）；页面载入时先回滚这条连接上没收尾的事务，窗口关了连接就丢掉。原来所有窗口共用一条连接，换模式时主窗口和设置窗口同时迁移，就报「cannot start a transaction within a transaction」（Rei 2026-11-19 Windows）。前端每条命令带上 `file`，不带就是生产库，老前端照旧能用。Rust 只认这两个文件名。
- 皮肤、语言、明暗这些界面设置两边共用。列表添加框的草稿、空白任务的记录按模式分开，演示里打的字不会出现在生产库里。

## 第一次启动怎么判断

没有 `mindough:demo-mode` 这个键时，先打开生产库看一眼：

- 生产库是空的（没有任务，也没生成过演示数据 `demo_seeded`）：算新装，进演示模式。
- 有任务，或者以前生成过演示数据：算老设备升级上来，留在生产库，不进演示模式。

看完在生产库的 meta 里记一笔 `demo_mode_checked`，再把判断结果写进 `mindough:demo-mode`，以后就不再判断了。生产库从此不再生成演示数据。

## 界面

- 侧栏最上面一个小徽标「演示模式」（中等宽度的图标栏只留烧瓶图标）。手机在抽屉标题下面。
- 鼠标悬停提示：「演示模式下的数据只存在这台设备上，不会同步。点一下可以关闭。」手机没有悬停，点按直接弹确认。
- 点了弹确认「关闭演示模式？」，确认后整页重新载入，换回生产库，侧栏上就没有这一项了。
- 设置 → 数据：
  - 「演示模式」开关。打开时回到演示库，演示库保留上次的样子；演示库还没生成过就生成一份。关的时候弹同一个确认。
  - 「重置演示数据」只在演示模式里有：只清演示库，重新生成。原来生产库里那个「重置演示数据」（清空本机全部）去掉了。
  - 「清除旧演示数据」只在生产库里、而且查到以前混进来的演示数据时才有，清完就不见了，规则见下面。
- 设置 → 账户：演示模式下顶上一行「演示模式下不同步」和「关闭演示模式」按钮，「用 Google 登录」灰掉。已经登录的账户照样显示，只是不同步。
- 双击底栏「我的一天」：提示「演示模式下不同步」。

## 换模式时做什么

1. 让编辑器失焦，发一次 `pagehide`（各处在这时存草稿），再等 Store 落盘。
2. 写 `mindough:demo-mode`。
3. 告诉别的窗口（Tauri 的设置窗口，事件 `mindough:relay` 的 `mode`），它们也先存好再重新载入。
4. 去掉地址里的 `?task=`，重新载入。

演示模式下这些都不跑：同步（`bindSync`）、附件上传、附件本机缓存的清理、两个「账户里还没有就写上去」的设置迁移。

## 清除旧演示数据

Rei 2026-11-19 定：全删，改过的也不留。代码在 core `demo-cleanup.ts`。

认哪些是旧演示数据，看它当初是不是演示那一批写进来的，不看最后一次改动：

- 演示那一批：这台设备写的，时间在 `demo_stamp`（生成演示数据时最后一笔）之前、离它不超过 10 分钟。
- 行现在的时间就在这一批里（没动过），或者 outbox 里还留着它当初那一笔（改过但还没同步，outbox 没清）。登录同步过的设备 outbox 清掉了，改过的认不出来，只能删没动过的。
- 从演示行派生出来的行一起删：id 里带着演示行 id 的，比如打卡达标后存档出来的已完成任务。
- 只挂在演示行上的「挂件」一起删：打卡记录、前后关系、任务和人物 / 类型的关联、我的一天、阶段等。
- 自己的任务、项目、人物、资料、日记引用着的演示行留着，比如自己的任务放在演示项目里、挂着演示人物。
- 偏好行（排序、视图设置）不管。
- 类型不能删：演示建的类型没人用了就改成「不显示」。

删除是普通的打墓碑，照常进 outbox。登录了的话，其他设备也会跟着删。

## 代定（等 Rei 确认）
