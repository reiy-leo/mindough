# Mindough（念头团）产品说明

名字（Rei 2026-10-24 定）：英文「Mindough」，中文「念头团」。中文界面显示念头团，英文界面显示 Mindough；网页标题、主屏幕上的名字、关于、菜单栏都跟着语言走。安装包名、bundle id、PWA manifest 的 name 还是 Mindough。

语言（Rei 2026-10-25「支持西、葡、俄、日、德、法、印尼」）：界面有中文、英文、西班牙语、巴西葡萄牙语、俄语、日语、德语、法语、印尼语九种。设置里选，或者跟随系统（系统语言不在这九种里就用英文）。日期、数字、币种、一周从哪天开始都跟着语言；农历只在中文界面出现；在线查资料时，中文界面按中文查，其他语言都按英文查。

## 给谁 / 解决什么
给 Rei 自己用（开放给谁登录还没定）。市面上的任务工具都靠多层分类来管；Mindough 让一件任务做完后自然接上下一件（一件或几件，FS：完成→开始），像前导图（PDM）。琐事另外记在一条 Agenda 式的时间线上。

## 核心概念
- 任务：只有 markdown 正文，没有标题，列表里显示的标题就是正文第一行，挂了资料的任务也一样（Rei 2026-11-03「任何任务的第一行都是标题」，见下面「资料库」里「标题和缩略图」）。第一行只能是纯文字（Rei 2026-11-03「任务的标题不渲染任何样式，或者列表，以及其他，任务标题是纯文本不渲染md」），见第 13 条「任务的第一行」。状态有 待办 / 进行中 / 完成 / 关闭，没有“取消”。完成和关闭都算结束，都能解锁后续，但只有完成算成就；两种都能重新打开。完成和关闭的任务标题都不划线，只变灰（Rei 2026-11-12「已完成和已关闭的任务不要删除线」）：列表行、看板卡片、我的一天、项目、已完成页、类型页、详情里的前后关系、任务链卡片都一样；正文里清单勾上的那一项照旧划线（那是正文格式，不是任务标题）。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS。前置都结束了（完成或关闭），这件就可开始，否则就是被阻塞；能跨项目；不能绕成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」），不用等对方，也不会解锁对方。详情里它和前后关系放在一起（「关系」）。
- 任务链（Rei 2026-10-23：「可以一键展示整个FS的一条线上的所有任务。当前一个任务只能展示它的前后任务，但前任务的前任务是没展示出来的」；同日：「整条线不要弹窗。每个步骤显示相对时间，而不是第几步。改名成‘任务链’」）：一眼看完这件任务前前后后的整条线。
  - 开关：在详情「关系」标题旁边，有先做完这些或做完后解锁时才出现。打开后不弹窗，就在「关系」里把「先做完这些 / 做完后解锁」换成整条任务链，关掉就恢复；「相关任务」照常在下面。开关只记在这台设备上，换一件任务也沿用。
  - 列什么：顺着前后关系，把这件任务所有的上游（前置的前置……）和下游（后续的后续……）都列出来，从最上游排到最下游，步和步之间是竖线加箭头。只算前后关系：相关任务、上游分出去的无关兄弟任务、删掉的任务和关系都不算。
  - 每一步写时间，不写第几步：都结束了，写什么时候完成的（「今天完成」「昨天完成」「3 天前完成」）；没结束，写最早的计划日期离今天多久（「今天」「明天」「5 天后」「已过 2 天」，过期是红色）；超过 30 天写日期；都没日期写「未定时间」。
  - 一步有几件（分叉、汇合）时纵向叠着，往里缩一点（详情栏窄，桌面和手机都这样）。每件显示状态（已完成 / 已关闭 / 进行中 / 还不能开始 / 可开始），当前这件高亮并标「这件」；接的不正好是上一步的全部时，写「接在「X」后面」。
  - 顶上是「已完成 N / 共 M」和进度条。点一件，打开它的详情。
- 任务详情不弹窗，三列布局（Rei 2026-10-23：「任务链不要再弹窗了，任务详情如果不弹窗最好了，最好做成三列布局」）。
  - 宽屏：侧边栏 | 当前视图的任务列表 | 任务详情，像 Things 3、提醒事项、邮件那样。点列表里的一件，右边显示它的详情，列表里那行高亮；没选中时，右边写「选一件任务查看详情」。日记、资料库、设置这类没有任务列表的页面，打开任务时才出现右边这一栏。
  - 右边这一栏能拖宽拖窄（这台设备会记住）；按 Esc 或点右上角关闭就取消选中，↑ ↓ 换一件。从 ⌘F 搜索、资料库、通知、链接打开的任务，也显示在右边。
  - 窗口窄一些（平板、小窗口）时，侧边栏收成一列图标，只剩列表和详情两栏；没选中时列表铺满。
  - 手机上详情整页推进来；点左上「返回」、从左边缘右滑、按系统返回键，都回到列表。
  - 选中的是哪件写在地址里，刷新后还在。任务列表页右下角不放新建按钮（Rei 2026-11-08），用顶上的添加框或按 N 开新建面板。
  - 三种皮肤各有样子：Apple 像提醒事项的检查器，WinUI 像邮件的阅读窗格，Material 3 是 list-detail 布局。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面。计时、计数、倒数日、今天打卡收成顶栏状态旁的小胶囊，点开看完整进度，也能开始、暂停。资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性卡片里的一行，没填时只有一行淡字。其余属性（类型、完成方式、日期、重复、提醒、项目）排成一行胶囊（Rei 2026-10-25 选方案 A · 胶囊行）：只显示设过的，默认的（没有类型、勾选完成、只做一次、没日期、不提醒、不放进项目）不显示。资料（含人物）不进胶囊，挂了就在胶囊下面按库分组列出来，见下面「资料库」（2026-10-28 起，原来的「资料库」「和谁有关」两个胶囊并进了资料）。每个胶囊是图标加值，放不下就换行，顺序固定：日期、完成方式、重复、提醒、项目、类型、心情、卡片颜色（Rei 2026-11-11 重排，2026-11-12 项目挪到类型前面；和「+」菜单同一个顺序，胶囊之间不画分隔）。点胶囊打开原来的选择器。电脑上悬停会出现小 ×，点一下恢复默认，可以撤销；手机上在选择器里选「无」那一项。行尾的「+」列出还没设的属性，选一项直接打开它的选择器。菜单分三组，组和组之间一条分隔线（Rei 2026-11-11）：日期、完成方式、重复、提醒 ｜ 项目、资料、类型 ｜ 心情、附件、卡片颜色（Rei 2026-11-12「项目移到资料那一组」，放这组第一个）；设过的、不适用的（重复任务没有日期，没日期时没有提醒，倒数日没有心情，只有倒数日有卡片颜色）不列，一组全空就连线一起不出。「附件」点了选文件（可以多选），加过附件它也还在（Rei 2026-10-25）。属性全设了、又不能加附件时才没有「+」。一个都没设时只有「+ 添加属性」。键盘上 Tab 到胶囊，Enter 打开，Backspace 或 Delete 清除。顶栏左边、状态胶囊后面有两个图标按钮（Rei 2026-10-29「任务和日记 editor 要行为一致」）：日期按钮，点开和「日期」胶囊同一个日期面板，设了日期是强调色，过期变红；图标按日期换（Rei 2026-11-08）：没日期是日历（calendar），今天是带勾的日历（calendar-check），以后是向右双箭头的日历（calendar-chevrons-right）、旁边写差几天，以前是向左双箭头的日历（calendar-chevrons-left）、旁边写差几天，数字不带正负号；「今天」按任务时区的今天算，和过期一样；日期段里含今天算今天，整段在以后按开始日算天数，整段在以前按结束日算；剪贴板按钮，剪贴板里有图片（桌面 app 里图片和文件都算）时才出现，点了直接加成附件、开始上传，同一份内容加过就不再出现。「关闭」（重复任务叫「不再打卡」）在顶栏「…」菜单里，不在底部（Rei 2026-10-17：「任务窗口底部的close按钮，移动到ellipsis下拉菜单中去」）。菜单分三组，用分隔线隔开：我的一天 ｜ 直接标为完成 · 关闭（结束了的换成「重新打开」/「恢复打卡」） ｜ 删除…。底部只留主操作（完成 / 计时 / 计数的快捷按钮 / 打卡）；结束了的任务，底部还是「这件事已关闭…」+「重新打开」。
  - 电影不显示「看到哪」（Rei 2026-11-08「任务属性 资料 影视：电影不显示看到哪」）：任务挂的影视资料是电影时，详情和新建面板里都没有「看到哪」那一行，第一行写的「S02E03」也不再顺手填进去；剧集照常。算电影：资料的「电影/剧集」选了电影；没选就看来源，TMDB 的电影是电影。挂了好几部，全是电影才藏。以前给电影填过的进度不删，只是不显示，改成剧集又会出来。列表行的小字、资料卡、资料详情本来就不显示「看到哪」，没改。
  - 剧集显示有哪些季（Rei 2026-11-11「资料库「影视库」里的剧集显示 seasons」）：影视资料详情里，剧集在资料下面多一节「季」，按 TMDB 列出每一季：海报小图、第 N 季（特别篇放最后）、首播年份、集数；TMDB 自己起了名字的季（不是「第 1 季」这种）再加一行名字。季的资料跟着这条资料存、跟着同步，打开不会每次都去拉：没有、来源换了、或者存了超过 30 天，打开时在后台补拉一次，拉不到就不显示。要有 TMDB 的剧集编号或 IMDb 编号；只有豆瓣编号的剧集不显示季。电影不显示。只是列出来，不记每季看到哪（看到哪还是任务上的那一行）。资料本身不是从 TMDB 来的，季下面单写一行「资料来自 TMDB」。
  - 新建面板的胶囊顺序（Rei 2026-11-11 04:27「也按任务详情『+』菜单」）：日期、提醒 ｜ 项目、资料、类型 ｜ 心情、相关任务（2026-11-12 项目跟着挪到资料前面），和详情「+」菜单同一份顺序（提醒要有日期才出现，打卡、倒数日没有心情）。新建面板没有「+」菜单，胶囊之间不画分隔线；完成方式、重复在新建面板是下面两段「怎么算完成」「多久一次」，不是胶囊，位置没动。新建面板没有附件。
  - 关系弹窗也列已完成的任务（Rei 2026-11-08「已完成的任务也在关系弹窗中显示」）：「先做完这些」「做完后解锁」「相关任务」挑任务时，完成、关闭的任务也在列表里，排在没做完的后面，字是淡色、行尾写「已结束」，点了照样连上。会绕成圈的、已经连着的照旧不列。
- 项目：有名称、图标、颜色、类型，里面放多件任务。老项目设过的开始 / 结束时间、默认资料库照常生效，界面上不再填（Rei 2026-11-02「删掉默认资料库，开始结束删掉」）。项目列表的卡片不显示起止时间段（Rei 2026-11-10「项目列表中 不显示项目时间段」）；侧栏里的项目本来就只有图标和名字，项目页页头 2026-11-04 起也不写日期段。
  - 新建和编辑是同一个面板（Rei 2026-11-02「和编辑窗口统一」）：图标、名字、颜色和图标选择，加一个「出现在我的一天」开关；只有标题（新建项目 / 编辑项目）和按钮（创建 / 保存）不一样。类型在项目页标题下面改。
  - 项目关联资料库（Rei 2026-11-10）：新建、编辑项目面板里有「资料库」下拉，能多选。选中的库里的任务自动放进这个项目，库里已有的和以后加进来的都算。
    - 「库里的任务」：任务挂了这个库的资料；人物库就是关联了人的任务。只选过库、没挂资料的老任务不算（资料库页里也看不到它们）。删掉的任务不算；完成、关闭、归档的照样挪进来，项目里看得全。开着严格模式时，完成和关闭的任务锁着，不挪。
    - 原来在别的项目里的任务，也挪进来。一件任务挂了几个库、几个库关联了不同项目，按任务里资料的顺序，第一个库说了算。
    - 一个资料库只能关联一个项目。下拉里已关联别的项目的库，名字下面写「已关联：某项目」。选它先弹确认「改关联到这个项目？」，确认后保存时改过来，它里面的任务一起挪到这个项目。
    - 取消勾选某个库：因为这个库挪进来的任务移出项目，到「没有项目」，不回原来的项目。手动放进这个项目的任务不受影响。
    - 以后给任务挂上这个库的资料，任务就进这个项目（新建时选了别的项目也一样）；资料全去掉了，任务移出项目。
    - 手动挪出：把库带进来的任务拖到别的项目、在详情里换项目或移出项目，这件任务就由你管，资料库不再自动把它拉回来。手动挪回关联的项目，又交回资料库管（以后取消关联时会移出）。重新关联这个库时，库里所有任务都会进来，包括以前手动挪出去的。
    - 项目归档了：不再收新任务，已经在里面的不动；取消归档后，这期间加进库的任务补进来。项目解散或删除了，关联就不生效（撤销后恢复）。删掉一个空资料库时，它的关联一起去掉。
    - 跟账户同步。多台设备同时改时，同步拉完一轮再按关联整理，任务只会换项目，不会丢。老版本 app 看不到这个下拉，它改过的任务照旧在原项目；它把任务换了项目，就当手动挪出。
  - 「出现在我的一天」（Rei 2026-11-02「项目编辑窗口中可以设置switch on/off不出现在我的一天中」）：默认开，跟着项目同步。开着时，项目里的任务到了该做的那天直接进我的一天（2026-11-08 起只有日期是今天或日期段含今天的才进，过期的、没到的不进）；关了就不自己进去，到了那天还在建议里。
  - 「默认日期：今天」（Rei 2026-11-09 03:52「项目编辑、新建弹窗中，添加"默认日期：今天" switch，on 则新建任务自动添加目标日期今天」）：新建 / 编辑项目面板里第二个开关，默认关，跟着项目同步（group.default_date_today，迁移 v20）。开着时，项目页添加框和项目页按 N 新建的任务日期填今天；日期是今天的任务照规矩直接进今天的我的一天（只一行，不会重复）。老客户端改了这个项目会把开关带丢，回到关。
  - 改名、换图标（Rei 2026-11-01「项目的图标、名称要可以编辑」）：项目页左上角点名字就地改，点图标换图标和颜色（只能选 Lucide 图标；老项目存的 emoji 照常显示）；··· 菜单里的「编辑…」也能改。
  - 图标样子（Rei 2026-11-04「类型的图标也和项目图标一样，共用样式和图标」「类型的颜色很少，也不好看，优化一点，然后统一组件」）：项目、类型、资料库的图标都是彩色圆角方块里一个白色图标（Material 是圆形），侧栏、项目卡片、项目页、任务行、搜索面板都一样，大小按地方调。换图标和颜色用同一个面板：上面 18 个颜色（按色相排，亮暗主题都看得清，最后一格能自己调），下面是图标网格。没选过颜色的老项目按项目自动配一个颜色，每台设备一样。
