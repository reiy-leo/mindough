# Mindough（念头团）产品说明

名字（Rei 2026-10-24 定）：英文「Mindough」，中文「念头团」。中文界面显示念头团，英文界面显示 Mindough；网页标题、主屏幕上的名字、关于、菜单栏都跟着语言走。安装包名、bundle id、PWA manifest 的 name 还是 Mindough。

语言（Rei 2026-10-25「支持西、葡、俄、日、德、法、印尼」）：界面有中文、英文、西班牙语、巴西葡萄牙语、俄语、日语、德语、法语、印尼语九种。设置里选，或者跟随系统（系统语言不在这九种里就用英文）。日期、数字、币种、一周从哪天开始都跟着语言；农历只在中文界面出现；在线查资料时，中文界面按中文查，其他语言都按英文查。

## 给谁 / 解决什么
给 Rei 自己用（开放给谁登录还没定）。市面上的任务工具都靠多层分类来管；Mindough 让一件任务做完后自然接上下一件（一件或几件，FS：完成→开始），像前导图（PDM）。琐事另外记在一条 Agenda 式的时间线上。

## 核心概念
- 任务：只有 markdown 正文，没有标题，列表里显示的标题就是正文第一行，挂了资料的任务也一样（Rei 2026-11-03「任何任务的第一行都是标题」，见下面「资料库」里「标题和缩略图」）。第一行只能是纯文字（Rei 2026-11-03「任务的标题不渲染任何样式，或者列表，以及其他，任务标题是纯文本不渲染md」），见第 13 条「任务的第一行」。状态有 待办 / 进行中 / 完成 / 关闭，没有“取消”。完成和关闭都算结束，都能解锁后续，但只有完成算成就；两种都能重新打开。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS。前置都结束了（完成或关闭），这件就可开始，否则就是被阻塞；能跨项目；不能绕成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」），不用等对方，也不会解锁对方。详情里它和前后关系放在一起（「关系」）。
- 任务链（Rei 2026-10-23：「可以一键展示整个FS的一条线上的所有任务。当前一个任务只能展示它的前后任务，但前任务的前任务是没展示出来的」；同日：「整条线不要弹窗。每个步骤显示相对时间，而不是第几步。改名成‘任务链’」）：一眼看完这件任务前前后后的整条线。
  - 开关：在详情「关系」标题旁边，有先做完这些或做完后解锁时才出现。打开后不弹窗，就在「关系」里把「先做完这些 / 做完后解锁」换成整条任务链，关掉就恢复；「相关任务」照常在下面。开关只记在这台设备上，换一件任务也沿用。
  - 列什么：顺着前后关系，把这件任务所有的上游（前置的前置……）和下游（后续的后续……）都列出来，从最上游排到最下游，步和步之间是竖线加箭头。只算前后关系：相关任务、上游分出去的无关兄弟任务、删掉的任务和关系都不算。
  - 每一步写时间，不写第几步：都结束了，写什么时候完成的（「今天完成」「昨天完成」「3 天前完成」）；没结束，写最早的计划日期离今天多久（「今天」「明天」「5 天后」「已过 2 天」，过期是红色）；超过 30 天写日期；都没日期写「未定时间」。
  - 一步有几件（分叉、汇合）时纵向叠着，往里缩一点（详情栏窄，桌面和手机都这样）。每件显示状态（已完成 / 已关闭 / 进行中 / 还不能开始 / 可开始），当前这件高亮并标「这件」；接的不正好是上一步的全部时，写「接在「X」后面」。
  - 顶上是「已完成 N / 共 M」和进度条。点一件，打开它的详情。
- 任务详情不弹窗，三列布局（Rei 2026-10-23：「任务链不要再弹窗了，任务详情如果不弹窗最好了，最好做成三列布局」）。
  - 宽屏：侧边栏 | 当前视图的任务列表 | 任务详情，像 Things 3、提醒事项、邮件那样。点列表里的一件，右边显示它的详情，列表里那行高亮；没选中时，右边写「选一件任务查看详情」。日记、资料库、设置这类没有任务列表的页面，打开任务时才出现右边这一栏。
  - 右边这一栏能拖宽拖窄（这台设备会记住）；按 Esc 或点右上角关闭就取消选中，↑ ↓ 换一件。从 ⌘F 搜索、资料库、通知、链接打开的任务，也显示在右边。
  - 窗口窄一些（平板、小窗口）时，侧边栏收成一列图标，只剩列表和详情两栏；没选中时列表铺满。
  - 手机上详情整页推进来；点左上「返回」、从左边缘右滑、按系统返回键，都回到列表。
  - 选中的是哪件写在地址里，刷新后还在。任务列表页右下角不放新建按钮（Rei 2026-11-08），用顶上的添加框或按 N 开新建面板。
  - 三种皮肤各有样子：Apple 像提醒事项的检查器，WinUI 像邮件的阅读窗格，Material 3 是 list-detail 布局。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面。计时、计数、倒数日、今天打卡收成顶栏状态旁的小胶囊，点开看完整进度，也能开始、暂停。资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性卡片里的一行，没填时只有一行淡字。其余属性（类型、完成方式、日期、重复、提醒、项目）排成一行胶囊（Rei 2026-10-25 选方案 A · 胶囊行）：只显示设过的，默认的（没有类型、勾选完成、只做一次、没日期、不提醒、不放进项目）不显示。资料（含人物）不进胶囊，挂了就在胶囊下面按库分组列出来，见下面「资料库」（2026-10-28 起，原来的「资料库」「和谁有关」两个胶囊并进了资料）。每个胶囊是图标加值，放不下就换行，顺序固定。点胶囊打开原来的选择器。电脑上悬停会出现小 ×，点一下恢复默认，可以撤销；手机上在选择器里选「无」那一项。行尾的「+」列出还没设的属性，选一项直接打开它的选择器；最后一项是「附件」，点了选文件（可以多选），加过附件它也还在（Rei 2026-10-25）。属性全设了、又不能加附件时才没有「+」。一个都没设时只有「+ 添加属性」。键盘上 Tab 到胶囊，Enter 打开，Backspace 或 Delete 清除。顶栏左边、状态胶囊后面有两个图标按钮（Rei 2026-10-29「任务和日记 editor 要行为一致」）：日期按钮，点开和「日期」胶囊同一个日期面板，设了日期是强调色，过期变红；图标按日期换（Rei 2026-11-08）：没日期是日历（calendar），今天是带勾的日历（calendar-check），以后是向右双箭头的日历（calendar-chevrons-right）、旁边写差几天，以前是向左双箭头的日历（calendar-chevrons-left）、旁边写差几天，数字不带正负号；「今天」按任务时区的今天算，和过期一样；日期段里含今天算今天，整段在以后按开始日算天数，整段在以前按结束日算；剪贴板按钮，剪贴板里有图片（桌面 app 里图片和文件都算）时才出现，点了直接加成附件、开始上传，同一份内容加过就不再出现。「关闭」（重复任务叫「不再打卡」）在顶栏「…」菜单里，不在底部（Rei 2026-10-17：「任务窗口底部的close按钮，移动到ellipsis下拉菜单中去」）。菜单分三组，用分隔线隔开：我的一天 ｜ 直接标为完成 · 关闭（结束了的换成「重新打开」/「恢复打卡」） ｜ 删除…。底部只留主操作（完成 / 计时 / 计数的快捷按钮 / 打卡）；结束了的任务，底部还是「这件事已关闭…」+「重新打开」。
  - 电影不显示「看到哪」（Rei 2026-11-08「任务属性 资料 影视：电影不显示看到哪」）：任务挂的影视资料是电影时，详情和新建面板里都没有「看到哪」那一行，第一行写的「S02E03」也不再顺手填进去；剧集照常。算电影：资料的「电影/剧集」选了电影；没选就看来源，TMDB 的电影是电影。挂了好几部，全是电影才藏。以前给电影填过的进度不删，只是不显示，改成剧集又会出来。列表行的小字、资料卡、资料详情本来就不显示「看到哪」，没改。
  - 关系弹窗也列已完成的任务（Rei 2026-11-08「已完成的任务也在关系弹窗中显示」）：「先做完这些」「做完后解锁」「相关任务」挑任务时，完成、关闭的任务也在列表里，排在没做完的后面，字是淡色、行尾写「已结束」，点了照样连上。会绕成圈的、已经连着的照旧不列。
- 项目：有名称、图标、颜色、类型，里面放多件任务。老项目设过的开始 / 结束时间、默认资料库照常显示、照常生效，界面上不再填（Rei 2026-11-02「删掉默认资料库，开始结束删掉」）。
  - 新建和编辑是同一个面板（Rei 2026-11-02「和编辑窗口统一」）：图标、名字、颜色和图标选择，加一个「出现在我的一天」开关；只有标题（新建项目 / 编辑项目）和按钮（创建 / 保存）不一样。类型在项目页标题下面改。
  - 「出现在我的一天」（Rei 2026-11-02「项目编辑窗口中可以设置switch on/off不出现在我的一天中」）：默认开，跟着项目同步。开着时，项目里的任务到了该做的那天直接进我的一天（2026-11-08 起只有日期是今天或日期段含今天的才进，过期的、没到的不进）；关了就不自己进去，到了那天还在建议里。
  - 改名、换图标（Rei 2026-11-01「项目的图标、名称要可以编辑」）：项目页左上角点名字就地改，点图标换图标和颜色（只能选 Lucide 图标；老项目存的 emoji 照常显示）；··· 菜单里的「编辑…」也能改。
  - 图标样子（Rei 2026-11-04「类型的图标也和项目图标一样，共用样式和图标」「类型的颜色很少，也不好看，优化一点，然后统一组件」）：项目、类型、资料库的图标都是彩色圆角方块里一个白色图标（Material 是圆形），侧栏、项目卡片、项目页、任务行、搜索面板都一样，大小按地方调。换图标和颜色用同一个面板：上面 18 个颜色（按色相排，亮暗主题都看得清，最后一格能自己调），下面是图标网格。没选过颜色的老项目按项目自动配一个颜色，每台设备一样。
  - 图标选择（2026-11-02 重做，Rei「确保设计符合对应的皮肤，项目弹窗中的这个图标部分也太难看了吧」；2026-11-04 改，Rei「编辑项目中的图标左右滚动，删掉搜索框，emoji不支持」，更正「是整个lucide icons section左右滑动，不再有文字标题，而是每列占满了占下一列，添加更多lucide icons，包括动物、植物」）：整块图标是一张网格，宽屏 5 行、手机 4 行，一列从上往下排满再排下一列，整块左右滑（触控板横滑、手指滑、Shift+滚轮都行）；没有组名，按常用、娱乐、学习工作、出行、生活、健康、动物、植物的顺序排，常用在最前。哪头还有图标，哪头就渐隐一点，滚动条藏起来。图标近 300 个，有猫、狗、鸟、鱼、兔子、乌龟、蜗牛、松鼠、熊猫，也有叶子、花、松树、阔叶树、棕榈、幼苗、四叶草、麦子、灌木。格子 38px（M3 是 40px）、间距 4px。没有搜索框，也不能用 emoji，只能选 Lucide 图标；老数据里存的 emoji 照常显示，打开时一个格子都不选中，点了图标才换。选中的格子是实心：Apple 系统强调色 + 白色图标（格子平时是浅灰填充、圆角 8），WinUI 浅强调色底 + 2px 强调色描边（圆角 4），M3 tonal 的 secondaryContainer（圆角 12，悬停 / 按下是 state layer）。打开时选中的那格滚到中间；方向键在格子间挪（↑↓ 同一列，←→ 隔壁列），Home / End 到头尾。新建项目默认的文件夹图标排第一个。
  - 项目的 ··· 菜单（Rei 2026-11-01「项目可以删除、解散。放在项目的ellipsis中，编辑也放这里」）：项目页右上角、项目列表卡片右上角（也能右键 / 长按卡片）、侧栏里那一项的右键都一样：编辑… ｜ 在侧边栏显示 · 归档 ｜ 解散项目… · 删除项目…。解散是项目没了、任务留着（没日期的回待安排）；删除是项目和里面的任务一起删。两个都先确认，写明几件任务，做完提示里能撤销。类型不能删，项目能。
  - 项目能归档（Rei 2026-11-05「项目可以归档」）：··· 菜单点「归档」，不用确认，提示里能撤销。归档只是先收起来，项目和任务都不动，「取消归档」后一切照旧。
    - 项目列表：归档的不在主列表，放在最下面折叠的「已归档（N）」一节，默认收起，点开是同样的卡片，菜单里是「取消归档」。按类型筛选只管主列表。侧栏里放进来的项目，归档了就不显示，取消归档后回来。
    - 归档项目里的任务：到了日子不自动进我的一天（「出现在我的一天」开着也不进），也不进建议；待安排、积压、时间轴、打卡、倒数日都不列，不提醒，桌面小组件也不算；给任务选项目时不列归档的项目（任务本来就在那个项目里时还显示它）。我的一天里归档前就在的（自己放的、自动进的）先藏起来，取消归档后回来；归档后自己又放进今天的照常显示。
    - 全局搜索（⌘F）照样搜得到归档项目和里面的任务。打开归档项目照常能看、能改任务，顶上一条提示「这个项目已归档」，后面一句「里面的任务不会进我的一天，也不在待安排、积压、时间轴里。」和「取消归档」按钮。
    - 存在 group.archived_at（迁移 v17），同步、导出导入都带上；老客户端不认这一列，当没归档。
  - 项目列表右上角只有一个小号的「新建项目」，手机上只留加号；右下角不放新建任务的浮动按钮（2026-11-01）。按类型筛选的胶囊用类型色当底色，字是黑或白、对比度至少 4.5:1，选中的是整块类型色（Rei 2026-11-01「不要用文字颜色，用背景颜色，注意对比度」；打卡、倒数日页的筛选也一样）。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，能设目标时长）、计数（做够一定数量；能设每次加多少和最多三个快捷按钮，比如喝 2000 mL 水点「+250」「+500」，点数字可以直接输总数或「+330」，加错了能撤销上一次，Rei 2026-10-26）、倒数日（等到某一天）。还能定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面上的叫法见 docs/COPY.md。
- 类型（Rei 2026-10-26 把打卡分类和项目分类合成一套）：名称、颜色、图标，任务（任何任务）能挂好几个（Rei 2026-10-28，docs/MULTI-TYPE.md），项目挂一个。内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），能加、改名、换颜色和图标、设成不显示，不能删（不显示的选择器里没有，挂着的照常显示）。只在侧栏「管理 → 类型」页里改，设置里没有类型（Rei 2026-10-28「去掉设置中的入口」）。类型页按方案 C 做（Rei 2026-10-28「按方案C执行」，docs/CATEGORY-EDITOR.md）：顶上一个搜索框，打开就能打字，名字、英文名、拼音首字母（「yd」→ 运动）都能搜，↑↓ 选、回车打开，没有同名的就多一行「新建“xxx”」；不搜时按大类分组：身体、生活、学习和工作、爱好、人，自己加的进「其他」，组能折叠，「不显示」的沉到最底下一组、名字变灰；每行只有彩色图标块、名字、用了几次。宽屏左右两栏，右边是选中类型的详情：图标块（点开换颜色和图标）、直接改的名字、常用 / 普通 / 不显示三档、换大类，下面是挂了它的任务和项目；窄屏点一行整页推进详情。页头和搜索框不动，只有列表自己滚，宽屏右边的详情也单独滚（Rei 2026-11-03「只有类型列表滚动，而不是整个页面」）。手机上左滑一行出「常用」「不显示」；电脑上 ⌘1 / ⌘2 / ⌘3 切三档，⌘F 或直接打字去搜索。改动马上保存，改档、换组都能撤销。顺序不用手排（Rei 2026-10-28 定「用「常用 + 最近用过」代替手动排序」）：选择器里标成常用的在前，其余按最近用过的先后排，没用过的按大类排；第一屏放常用的（不足 6 个用最近用过的补齐）+「更多」，「更多」里能搜，底部「管理类型…」去类型页。打卡、倒数日、项目页按类型筛选、分组，只列用到的。
- 资料库：内置的库有影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱，人物就是人物库；也能自己建库。
  - 类型和资料库平级、互不连接（Rei 2026-10-28：「类型是类型，资料库是资料库，是平级的」，docs/MULTI-TYPE.md）。一件任务能挂好几条资料，可以来自不同的库，比如几个人加一部电影；挑资料不改类型，换类型也不动资料。

0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）。顶部添加框只有输入框，右边不放「从全部任务添加 ⌘K」（Rei 2026-10-26「删除从全部任务添加的按钮」），从全部任务挑还是按 ⌘F / Ctrl+F 搜索。在框里按回车，任务进今天并马上打开，和点一行一样（Rei 2026-10-26「从这里添加任务后立即打开任务」）：宽屏光标留在框里，能接着加，详情跟着换成最新那件；手机整页推入，键盘收起。我的一天、待安排、可做三页的中间列不放页头（Rei 2026-10-26「我的一天、待安排、可做的中间列的header去掉，换成输入框」），最上面就是添加框：待安排和可做加进待安排；原来副标题里的日期、件数挪到添加框下面一行小字；手机上标题在顶栏。「建议」行尾不放原因徽章（今天到期…），也不放「+ 加入」按钮（Rei 2026-10-25「任何情况下都不显示这两个按钮」）：到期看行里的日期，加入用这一行的长按菜单（手机；所有任务列表行都有：查看详情 ｜ 加入 / 移出我的一天）或详情里的太阳。任务列表行没有右键菜单（Rei 2026-11-08 23:39「任务列表都删掉右键菜单」）：右键什么都不弹，也不出浏览器 / 系统菜单；菜单里的事详情都能做（点行开详情，顶栏太阳加入 / 移出我的一天，「…」里置顶）。手机长按菜单还在。我的一天列表的行尾也不放 ×（Rei 2026-10-25「删除my day中的条目右侧的x按钮」），移出同样走行菜单，或详情里的太阳。「建议」能关（Rei 2026-11-01「我的一天中的建议，可以toggle on/off」）：设置 → 任务 →「我的一天」里的「显示建议」开关，默认开；建议那段标题右边「…」→「隐藏建议」关的是同一个，关完弹提示，写着去哪儿打开，也能直接撤销。关着时那段不显示，也不去算建议。只存在这台设备上，不同步。项目里的任务不进建议，直接进我的一天（Rei 2026-11-02「直接出现在我的一天，而不是出现在的建议里」）：日期是今天或日期段含今天、倒数日到了、今天要打卡、刚解锁的，只要它的项目开着「出现在我的一天」，那天自动加进列表（2026-11-08 起只加当前的：过期的、还没到的都不自动加，Rei「只有当前的显示在我的一天，过期的、没到的都不显示」；早上已经自动加进来、后来过期的那天也不显示，自己手动加的照常；没日期的打卡、倒数日、刚解锁照旧。项目里过期的任务不进建议，在积压里看）；不在项目里的照旧只建议。从行菜单「移出我的一天」后，当天不会再加回来；第二天还该做就再加。这和「显示建议」开关无关。多台设备各自加的是同一行，不会出现两条。添加框打长了会折行、往下长，最多 6 行，再多在框里滚，不左右滚；回车照旧添加，Shift+回车也不换行，粘贴进来的换行和以前一样去掉（Rei 2026-11-08「任务输入框支持换行」，22:38 说明是长了要多行显示）；时间轴每天的添加框一样。添加框和下面那行日期、件数固定在列表顶上，列表在它下面滚（Rei 2026-11-02「所有的任务输入框都不随列表滚动」），待安排、可做、项目页的添加框也一样，日记页右栏的输入框（连同工具栏、待发的小图）也固定在条目上面（Rei 2026-11-02「日记中的输入框也不滚动」），输入框太长时最多占一小块、在框里滚；滚动后框下面多一条细线。能拖动排序的列表（我的一天、待安排、资料库、字段）拖完不留高亮：不选中被拖的行，不打开详情，鼠标 / 触屏拖完也没有焦点环；键盘拖动保留键盘焦点（Rei 2026-10-25「拖拽调整顺序后不要highlight」）。待安排：还没定哪天做的事都在这里；新建的任务默认进这里，从我的一天新建的才直接进今天
   - 分两段（Rei 2026-11-08「我的一天中，未完成、完成两个section显示」）：以前做完的任务沉到同一张清单的底部，现在分成「未完成」和「已完成」两段，未完成在上。只有一段时不放段标题，看起来和以前一样。「已完成」包括完成的、关闭的、今天已经打够卡的打卡（和「x/y 已完成」的判断一样，只是关闭的不计入那个数）；那段标题能点着收起，默认展开，收没收只记在这台设备上。拖动排序只在自己那段里拖；勾上就挪到已完成段，取消勾选回到未完成段。
   - 新加的排最上面（Rei 2026-11-08「添加到我的一天的任务放在最上面」）：手动加入、从建议加、在我的一天添加框新建、带回今天、项目任务自动加入，都排在未完成段最上面，后加的在上。拖过的顺序照旧，新加的插在它们上面。自动加入的按「它变成今天该做」的时刻排：一早就该做的排在当天手动加的下面，白天改了日期、刚解锁才进来的排在那一刻之前加的上面。
   - 改日期不是今天就移出（Rei 2026-11-08「用户设置的日期不是今天时 取消我的一天」）：在我的一天里的任务，从任何地方（日期胶囊、日期按钮、待安排的「安排日期」、时间轴拖动、⌘F 等）把日期改成以后或以前的日子，就从今天的我的一天移出，项目自动加入当天也不再加回来。改成今天、日期段含今天、清空日期都留着：清空日期说明还没定哪天，人已经放进今天了，就不替他拿走。
   - 日期设成今天就加入（Rei 2026-11-08「如果日期设置的今天，自动添加到我的一天」）：反过来也一样。从任何地方把日期改成今天，或者日期段改完含今天（以前不含），任务就放进今天的我的一天，排在「未完成」最上面，和手动加入一样；新建时带今天的日期（新建面板、添加框、⌘F 新建、深链接）也放进来。当天从我的一天移出过的，又把日期改成今天，也重新放回来：这是自己改的日期。已经在里面的、置顶的、做完或关闭的、归档的打卡、归档项目里的、重复的打卡不管。倒数日按它的开始日算，只改目标日不算。别的设备同步过来的改动不会再加一次，只收到这台写的那一行。把日期改回别的日子就按上一条移出；改回没日期的留着。
   - 置顶（Rei 2026-11-08「任务支持置顶，置顶的任务在我的一天中永远显示，直到用户手动关闭」）：任务行的长按菜单（手机）、任务详情 ··· 菜单、打卡页一行的菜单里点「置顶」。置顶的任务每天都在我的一天「未完成」段最上面，比新加的还靠上；几件都置顶时，后置顶的在上。改日期、项目关了「出现在我的一天」都不影响它；菜单里不再给「加入 / 移出我的一天」，点太阳按钮会提示「置顶的任务每天都在我的一天里，要移出先取消置顶」。置顶的不能拖动排序。置顶的图钉是红色的，放在勾选圆圈前面、拖动把手那格（Rei 2026-11-09 01:03「置顶的任务的pin放在circle前面，就是原本drag handle的地方，颜色用红色」）：我的一天里置顶的不能拖，那格只有图钉；待安排、项目看板里图钉本身还是拖动按钮，照样能拖（看板要能拖到别的状态）；没有把手的列表（项目列表视图、时间轴、已完成、积压、类型 / 人物 / 资料里的任务）图钉放在行左边的留白里，圆圈不挪。颜色用各皮肤的危险红（--danger），亮暗都有。做完（或关闭）那天它在「已完成」段，第二天起不显示，但还是置顶，重新打开又回到最上面；打卡每天都在，当天打完进「已完成」段。归档项目里的、打卡归档了的不显示。置顶的不进「昨天没做完」、建议和待安排。侧栏我的一天的数字、小组件都算上它。「取消置顶」回到普通任务：今天本来在我的一天里的照常显示，不在的就不显示了。存在 task.pinned_at（迁移 v18），同步、导出导入都带上，老客户端不认这一列，当没置顶。
   - 今天要打的打卡自动在我的一天里（Rei 2026-11-09 01:27「打卡任务，如果今天有节点，也要显示在我的一天中」）：按重复规则今天要打的打卡（没归档、没「不再打卡」、不在归档项目里）不用加就在，排在手动加的后面，行里直接 +1 / 打卡 / 计时；达标了进「已完成」段（达标后不能再加，撤销上一次能退回来）。今天不用打的不显示。和置顶一样不写我的一天的表（各设备每天自己算出来）；拖动排序过的那一行才落成普通的行记住位置。能移出当天：行菜单或详情里的太阳「移出我的一天」，当天不再出现，第二天照常（移出记成一条墓碑，会同步，别的设备也不出现）；移出后想再加回来就是普通的「加入我的一天」。这些打卡不再出现在「建议」里（以前「今天要打卡」是一条建议）。分区：按项目分时归到它的项目（没项目的在「没有项目」），按心情分时没记心情的在「没有心情」。项目开着「出现在我的一天」时，项目里的打卡以前就会自动写行进来，照旧。

## 不做
多人协作与共享、多层文件夹分类。

- 列表行状态标记（Rei 2026-10-27「整行标题变色的，不要用这种方式，可以用标题下方用不用的图标来标记…hover显示tooltip」）：状态不给标题上色，只在标题下用图标标：🔒+数字=还在等 N 件事、绿色插头=可开始（Lucide plug，2026-11-09 起，原来是蓝色开锁）、播放圈=进行中、禁止=已关闭、地球+偏移=时区、链接+数字=相关任务；鼠标悬停 400ms 显示文字（ui/HoverTip），触屏不弹，文字同时是读屏标签。顺序：类型、组、日期、日期段、时区、重复、相关任务，然后是状态图标（Rei 2026-10-27「状态可以放在属性后面」）。资料名不写在这一行（2026-11-03）。
- 列表行不显示副标题（Rei 2026-10-27「副标题永远不在列表显示」）。2026-11-03 起任务没有副标题了：标题就是正文第一行，资料只显示缩略图。
- 列表收紧（Rei 2026-10-27）：页面上下左右留白 20px，分组之间 20px，行高 40px、行上下内边距 3px。macOS 无标题栏时，中间列顶部只留 10px 拖动条（红绿灯只在侧边栏，不用给中间列留 38px）。
- 出错不白屏（Rei 2026-10-27「点击了一个任务…页面变空白」）：页面和详情各包一层 ErrorBoundary，渲染出错只换掉那一块，显示出错信息和「再试一次」，换任务或换页面自动重试。
