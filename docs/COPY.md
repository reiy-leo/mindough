# 念头团（Mindough）界面文案

界面上的每个字都按这份文档写。加新文案或改文案时，先查术语表；术语表里没有的词，按“语气原则”写，写完补进来。

## 语气原则
- **简洁**：一句话说完一件事；能用 4 个字就不用 8 个字。按钮用动词（「添加」「完成」「重新打开」），不加“请”“点击”。
- **口语但不随便**：像一个靠谱的朋友在旁边提醒，不卖萌、不用网络用语、不加感叹号堆砌；空状态给一句安心或下一步（「没有要先做的事，随时可以开始。」）。
- **不用技术术语**：界面上不出现 FS、DAG、markdown、正文、节点、依赖、墓碑、OPFS、wasm、里程碑代号（M1 / M2）这类词。怎么做的写在代码注释和 docs 里，不写在界面上。
- **说结果，不说机制**：「已删除」而不是“已删除（墓碑保留，同步后各端一起删除）”；「数据先存在这台设备上，离线也能用」而不是“本地优先，界面永不等待网络”。
- **自动保存不用提**：所有改动都会自动保存，不要写“离开输入框自动保存”之类的说明。
- **提示放进提示里**：写法提示只放在 ? 图标的悬停提示里（新建面板：「直接这样写，会自动排好版：」+ `# 标题` `- [ ] 清单` `**粗体**`），不在输入框下面写一整句。
- **数量词**：任务用「件」（「还在等 2 件事」），打卡用「次」（「已连续 5 次」），人用「位」或省略。
- **HTTP 状态码**：出现时都附中文说明，如「503 服务不可用」「408 请求超时」。
- **标点**：中文全角标点；引用任务名用「」；数字和中文之间留半角空格（「每次 10 分钟」）。

## 写在代码里的约定
- 完成方式的名称与一句话说明在 `packages/core/src/types.ts`（`COMPLETION_MODE_LABEL`、`COMPLETION_MODE_HINT`），界面上都从这里取，不要自己写。
- 把属性说成人话的函数在 `packages/core/src/describe.ts`（`describeCompletion`、`countdownPhrase`、`friendlyDate`、`formatTarget`）；`describeRecurrence` 在 `recurrence.ts`。
- 站点编号（IMDb / 豆瓣）的占位与提示、常见网站的显示名在 `packages/core/src/links.ts`（`SITES`、`detectLinkLabel`）；币种中文名与符号在 `money.ts`（`CURRENCIES`）；季集的显示在 `episode.ts`（`formatEpisode`）。
- 资料库的叫法（库名、短名、选择框占位、量词）在 `packages/core/src/library.ts` 的 `LIBRARY_COPY` / `libraryCopy()`，界面从这里取。
- 内部的枚举值（`once` / `timer` / `count` / `countdown`，状态 `待办` / `进行中` / `完成` / `关闭`，派生状态 `可开始` / `被阻塞`）不随文案改。
- 界面语言：代码里都写 `tr('中文原文')`（`trx` 带元素的整句，`trc('语境', '中文')` 同一个词在不同位置英文不同时用）；英文在 `packages/core/src/i18n-en.ts`（core 的说法）与 `apps/client/src/i18n/en.ts`（界面）。内置数据（资料库名、字段名、选项、单位、正文模板、27 个打卡分类、网站名）存中文原样，显示时 `dataLabel()` 换成英文（`i18n-data-en.ts`），用户改过的名字照用户写的。`apps/client/src/i18n/i18n.test.ts` 检查：没有漏翻的中文、每个 key 有英文、每个内置名字有英文。

## English

界面英文的写法（Rei 2026-10-16「添加中英文支持」；设置 → 语言：跟随系统 / 中文 / English，跟随系统时系统是中文就中文、其余英文，存进同步的偏好）。参照 Things 3 / Apple：短、具体、不客套。

- **大小写**：导航、页面标题、按钮、菜单项、分段控件用 Title Case（My Day、New Task、Bring All to Today、Sign In with Google）；说明、提示、toast、占位用 sentence case（“Changes sync to your other devices automatically.”）。
- **标点**：弯引号 “ ” 与撇号 ’；省略号用一个字符 …（Manage Categories…）；破折号 — 两边空格；句末句号只给完整句子，标签、按钮不加。英文的引号、撇号、省略号用拉丁字体字形（`app.css` 的 `Mindough Latin Punct`），不用中文字体的全角字形。
- **数字与复数**：一律阿拉伯数字；单复数用 `Intl.PluralRules`（1 task / 3 tasks、1 day to go / 12 days to go）；序数 1st 2nd 3rd（Monthly on the 15th）。
- **日期**：Intl（en-US）：Fri, Oct 16；不在今年带年份 Mon, Mar 1, 2027；一周仍从周一开始；星期选择钮用 M T W T F S S（读屏读全名）。
- **语序**：整句翻，不拼接。中文「还有 12 天」→ “12 days to go”，「已过 3 天」→ “3 days ago”，元素（粗体数字、输入框）用 `trx` 插在英文语序里。

## 其他语言

Rei 2026-10-25：「支持西、葡、俄、日、德、法、印尼」。设置 → 语言是一个下拉：跟随系统，加九种语言（每种用它自己的写法：中文、English、Español、Português (Brasil)、Русский、日本語、Deutsch、Français、Bahasa Indonesia）。跟随系统时按系统语言的顺序找第一个支持的，都不支持就用英文。

怎么译：

- **照英文的意思译，不照中文逐字译**。英文是第一份译文，说法已经按 Things 3 / Apple 定过；其他语言参照各自系统（iOS / macOS、Android）里同类功能的本地叫法，导航尤其如此。
- **app 名字**：除中文叫「念头团」，其他语言都叫 Mindough。
- **「打卡」**：其他语言都译成「习惯」那个词（Hábitos、Привычки、習慣、Gewohnheiten、Habitudes、Kebiasaan），按钮上的「打卡」用「记下 / 勾掉」一类的动词。
- **葡萄牙语用巴西葡萄牙语**（pt-BR）。系统是葡萄牙的 pt-PT 也显示 pt-BR。
- **日期、数字、币种**都交给 Intl，跟着语言走：一周从哪天开始也按 Intl（中文、德、法、俄、西周一；英文、日文、巴西葡语、印尼语周日）。农历只在中文界面出现。
- **复数**用 ICU 写法 `{n, plural, one {…} other {…}}`；俄语要写 one / few / many 三种。
- **法语标点**：`: ; ? !` 前面和 `«` 后面、`»` 前面要空，用不换行空格（`:` 前 U+00A0，其余 U+202F），不然标点会单独折到下一行。测试会查。
- **数字和单位**：中文、日文不空（「3/8杯」），其他语言空一格（「3/8 Gläser」）。
- **键名**：「按回车」在德语写 Zeilenschalter（Apple 德语的叫法），其他语言写 Return / Intro。
