# 项目里程碑（Milestone）

Rei 2026-11-13 09:19：「项目支持milestone。项目中添加或修改任务：添加新属性"阶段、里程碑"，这个属性只有项目中可以设置。每个项目中的这个属性的列表都不一样。显示为一个可搜索的dropdown，搜索可以选择，也可以新建。」

一句话：每个项目一张自己的里程碑列表，项目里的任务可以挂一个里程碑。

## 叫法

- 中文「里程碑」（Rei 2026-11-13 10:09 定的，原来叫「阶段」），英文 Milestone。其余语言：Hito、Marco、Этап、マイルストーン、Meilenstein、Jalon、Tonggak（外语待母语者看）。
- 图标用 Lucide `milestone`。

## 规则

- 一件任务最多一个里程碑。
- 只有在项目里的任务能设。不在项目里的任务，属性菜单里没有「里程碑」。
- 里程碑属于项目。任务移出项目或换到别的项目，里程碑清掉；换回原项目也不恢复。
- 同一个项目里里程碑不重名：去掉首尾空格、连续空格并成一个，比较时不分大小写（全角半角算一样）。两个项目可以各有一个「设计」。
- 没有删除，只有归档。归档的不在下拉里列；已经挂着它的任务照常显示，下拉里它带「已归档」。搜同名再点「新建」，就是把它取消归档并选上。

## 下拉怎么用

1. 在任务详情点「+」，选「里程碑」（在「项目」下面）；设过的话直接点里程碑胶囊。
2. 打字过滤。中文名也能用拼音首字母或全拼搜，比如「sg」找到「施工」。
3. 要的没有，就在最后一行「新建里程碑“xxx”」上回车或点一下，建好直接选上。
4. 键盘：↑↓ 移动，回车选，Esc 关掉。
5. 底部「清除里程碑」去掉任务的里程碑。
6. 每行右边「…」：改名（行里直接改，回车存，Esc 取消；空的、和别的里程碑重名的存不了），归档 / 取消归档（归档后提示里能撤销）。

新建面板里选了项目，才会出「里程碑」胶囊；换项目时清掉已选的里程碑。

## 在哪儿看到

- 任务详情：胶囊行里，紧跟项目胶囊。
- 项目页列表、看板：任务行第二行一个灰色小标签。
- 项目页「分区」→「按里程碑」：按里程碑列表的顺序分段，归档但还挂着任务的里程碑排在后面，没设的在最后「没有里程碑」。这时行里不再写里程碑。
- 全局搜索：搜里程碑名能找到挂了它的任务。

## 数据

- 新表 `milestone`：`id`、`group_id`（项目）、`name`、`sort`（列表先后，新建的排最后）、`archived_at`（空 = 没归档）、`created_at`，加上同步通用的 `updated_at`、`deleted`。
- 任务新列 `task.milestone_id`，空 = 没设。
- SQLite 迁移 v24。云端 Worker 存的是通用的「表 + 行」，不用改。
- 同步照旧按行 LWW。本机写任务时自动核对：不在项目里、里程碑不是这个项目的，就清成空。两台设备同时一边换项目、一边设里程碑，同步后可能对不上，这时界面当没有里程碑。
- 老客户端（v23 以前）推上来的任务行没有 `milestone_id`：项目没变就沿用本机的值；项目变了当成清掉。老客户端不认识 `milestone` 表，拉到也不显示。
- 导出：任务文件写 `milestone`（id，注释带名字），里程碑列表在 `_meta/milestones.json`。导入时里程碑要是这件任务所在项目的，对不上就当没设。
